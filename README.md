# EQUALIZER

EQUALIZXR-13 es una aplicación web interactiva que funciona como un ecualizador de audio de 7 bandas. Permite a los usuarios cargar archivos de audio locales, modificar diferentes rangos de frecuencia y escuchar los cambios en tiempo real mediante la Web Audio API. Además, incluye presets predefinidos para distintos géneros musicales, controles de reproducción y un visualizador de frecuencias que muestra la respuesta del audio mientras se reproduce.

HTML5 para la estructura de la interfaz.
CSS3 para el diseño visual y la adaptación a diferentes tamaños de pantalla.
JavaScript para la lógica de reproducción y procesamiento de audio.
Web Audio API para la creación y control del ecualizador.
p5.js para la generación del visualizador de frecuencias
