Place an initial audio file here so the app has something to play by default.

- Filename: initial.mp3
- Location: assets/initial.mp3 (relative to project root)

If `assets/initial.mp3` exists when the page loads, the app will load it automatically.
If the file is not present, the UI will show the upload/drop prompt as before.

Recommended: add a short example track (MP3, WAV or M4A). Keep the file size small for quick loading during development.

Favicon
-------
Place a site icon at `assets/favicon.ico` (or `favicon.png`). The app's HTML includes a link tag pointing to `assets/favicon.ico`. Add your icon file there to have it display in browser tabs, bookmarks, and on mobile home screens.
